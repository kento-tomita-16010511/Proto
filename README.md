# Unity 個人開発サンプル

## 概要

本リポジトリは、Unityを用いた個人開発のサンプルプロジェクトです。

-これをベースにいろいろなゲームをClaudeCodeに渡し、共通化するツールを作っていることを目的とします。

## 開発期間

約2週間

## 開発環境

* Unity 6
* C#
* Claude Code を活用したAI支援開発

## 開発について

本プロジェクトでは、AI（Claude Code）を開発支援ツールとして活用しています。

ゲームの企画・仕様検討・実装方針の決定・動作確認・修正は自身で行い、実装の一部でAIを活用して開発を進めました。

提出用サンプルのため、コードレビューやリファクタリングが十分ではない箇所がありますが、実装例としてご確認いただければ幸いです。
